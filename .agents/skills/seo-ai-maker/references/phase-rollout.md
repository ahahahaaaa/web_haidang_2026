# Phase Rollout

## Phase 1

- Make crawlable public pages explicit
- Add `sitemap.xml`
- Ensure `robots.txt` points to the sitemap
- Confirm public routes are indexable

## Phase 2

- Align schema with page type
- Add concise answer-summary blocks on key pages
- Add internal links between service, package, estimate, project, and blog pages

## Phase 3

- Build topic clusters and landing pages for target keyword groups
- Add comparison tables, FAQs, checklists, and query-focused sections
- Expand location and pricing support pages where the business truly serves them

## Phase 4

- Measure impressions, indexed pages, and long-tail query coverage
- Refresh priority pages regularly
- Tighten internal linking from new content back to money pages
